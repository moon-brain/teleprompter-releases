# Teleprompter Studio — descargas

Instaladores de Windows de **Teleprompter Studio**.

- **Última versión:** [Releases → Latest](https://github.com/moon-brain/teleprompter-releases/releases/latest). Descarga `Teleprompter-Studio-Setup-X.Y.Z.exe`.
- La aplicación instalada busca aquí sus actualizaciones (`latest.yml`) y avisa cuando hay una nueva.

Este repositorio no contiene código: las Releases se publican automáticamente al lanzar cada versión.
